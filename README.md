The AppBuilder SDK is a tool that helps developers build AI-native applications. It provides a variety of components, including:

* **Large Language Models (LLMs):** Components for text generation, translation, and other language-related tasks.
* **Retrieval-Augmented Generation (RAG):** Components that combine the power of large language models with the ability to retrieve information from a knowledge base.
* **Generative Business Intelligence (GBI):** Components that use AI to generate insights from business data.
* **AI Capabilities:** A wide range of components for tasks such as speech recognition, image recognition, and more.
